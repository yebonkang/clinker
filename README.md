Compared to V2, added an option to show no. of blast mismatches. Enable it by adding `-sm`

```bash
$ python -m clinker.main *.gb -o show_mismatch.tsv -sm -p show_mismatch.html
```
Then open the output HTML file, and tick the **"Show link mismatches:"** option
